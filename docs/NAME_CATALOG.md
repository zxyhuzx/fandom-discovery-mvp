# 이름 검색 카탈로그

## 2026-10-26 확장

기존 **16개 작품·그룹 / 56명**에서 **194개 작품·그룹 / 1,323개의 작품별 캐릭터·버튜버 항목**으로 확장했다. 각각 12.1배, 23.6배다. 같은 작품의 시즌·영화를 별도 작품으로 늘리지 않았으며 아이돌은 추가하지 않았다. 작품마다 최대 12명의 등장인물을 선정했다. 다른 작품에 출연한 같은 인물의 관계는 별도 항목이다.

- 추가 178개 작품과 1,267개 인물 관계는 `data/expanded-catalog.json`에 이름·별칭·원문 ID/URL만 보관한다. 소개 글·이미지·가상 판매 정보는 포함하지 않는다.
- 추가 인물의 표시 이름은 한국어 편집 표기 207개, 확인된 Wikidata 한국어 이름 65개, 원문 유지 995개다. 기존 목록은 한국어 표기를 유지한다. 동명 사물·실존 인물로 잘못 번역되지 않도록 Wikidata 설명에서 가상 인물임을 확인한 경우에만 별칭을 사용했다.
- 영문·일본어 검색은 등록된 별칭만 지원한다. 한국어 표기가 없는 인물은 원문을 표시한다. 예: `ワンピース` → 원피스, `モンキー・D・ルフィ` → 원피스 · 몽키 D. 루피.
- 출처: [Anime Character Offline Database](https://github.com/arda-/anime-character-offline-database/tree/prod), 원본 생성 시각 `2025-08-14T04:32:44.430Z`, 가져온 날짜 2026-10-26. 이름 자료: [Wikidata](https://www.wikidata.org/). API 속도 제한으로 미확인 번역은 추측해 채우지 않았다.
- 원본 저장소 데이터 라이선스 ODbL 1.0 / DbCL 1.0에 따라 이름 데이터와 편집 파생물을 공개한다. Wikidata는 CC0. 원본 JSON 메타의 MIT 표기보다 저장소의 데이터 라이선스 문서를 기준으로 했다. 코드 라이선스와 별개다. [원본 라이선스](../data/CHARACTER_SOURCE_LICENSE.md), [공개 출처 화면](../data-sources.html).

수정 시 `scripts/import-catalog.py`와 `data/korean-curation.json`을 사용한다. 공개 원본 저장소의 `latest/characters.min.json`을 `data/character-source.json`으로 먼저 받아야 한다. 원본/조회 캐시는 gitignore로 배포·커밋에서 제외한다. `--offline`은 기존 캐시만 사용하며, 캐시가 없으면 편집 표기와 원문만 사용한다.

프런트와 DB 정규화는 함께 변경한다. `node scripts/build-name-migration.mjs supabase/migrations/<새_버전>_names.sql`로 **새** 마이그레이션을 생성·적용한다. 이미 적용한 파일을 덮어쓰지 않는다. 출처·이름 연결과 최소 10배 수량은 단위 테스트로 검사한다.

영문·일본어 이름은 assets/name-catalog.js에 등록한 별칭을 기준으로 검색하며 결과/선택/저장은 한국어 이름을 사용한다. 예: Suisei / 星街すいせい → 홀로라이브 · 호시마치 스이세이. Hinata 입력은 하이큐·나루토 후보를 각각 표시한다. 기존 작품에도 일본어 제목과 일부 주요 캐릭터 영문·일본어 별칭을 연결했다.

자동 번역이나 전체 이름 사전은 아니다. 등록하지 않은 이름은 원문을 유지하고 직접 입력할 수 있다. 버튜버/VTuber 검색과 장르 필터도 제공한다. 실제 버튜버 굿즈를 수집하거나 판매 데이터를 자동 생성하지 않는다.

관심사 추가·관리자 게시물 입력에서 한국어 대표 이름으로 정규화한다. 기존 데이터도 표시할 때 한국어 대표 이름을 사용한다. DB의 normalize_work / normalize_character와 게시물 알림·모의 대기열 매칭에도 동일한 별칭을 연결했다. 새 언어 별칭을 추가할 때 프런트와 DB 마이그레이션을 함께 갱신해야 한다.
