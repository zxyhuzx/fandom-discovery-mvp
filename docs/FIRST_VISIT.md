# 첫 방문 흐름 (2026-11-03)

루트 `/`는 긴 소개 화면 대신 첫 방문 선택 흐름을 표시한다. 기존 서비스 홈 `/app.html#home`과 세 탭은 유지한다.

1. 인사: “안녕하세요. 별을 주우러 오셨나요?”와 시작 버튼. 검색창·내비게이션·다른 서비스 영역은 표시하지 않는다.
2. 작품·장르: 기존 이름 카탈로그를 검색하고 여러 작품·그룹을 고른다. 애니·만화/게임/웹소설·웹툰/버튜버는 작품을 좁히는 분류 필터이며, 별도 장르 전체 구독 데이터로 저장하지 않는다.
3. 캐릭터: 고른 작품에 속한 인물만 여러 명 선택한다. 캐릭터를 고르지 않으면 작품 전체를 관심사로 취급한다. 이전 단계로 돌아가 선택을 바꿀 수 있다.
4. 연결: 선택 내용 확인 → 기존 Supabase 카카오 PKCE 로그인. 이미 로그인했다면 재인증 없이 관심사를 저장한다. 현재 제공하는 알림은 웹 알림이며 카카오톡 메시지 발송은 준비 중임을 명시한다.
5. 연결하지 않고 다른 별들 탐색하기 → 현재 서비스 홈. 둘러보기는 로그인·DB 저장 없이 가능하다.

선택한 항목은 `byeoljup-welcome-draft-v1`로 브라우저에 보관한다. 계정 저장은 연결 버튼을 명시적으로 누른 경우에만 진행한다. OAuth 전 `sessionStorage`에 연결 표시를 남기며, 콜백 후 앱이 검증된 임시 관심사를 기존 계정 관심사와 합쳐 `save_my_interests`에 저장한다. 기존 관심사는 덮어쓰지 않는다. 전체 100개 제한·작품과 캐릭터 관계·별칭 중복을 확인한다.

저장 성공 시 브라우저 임시 선택/연결 표시를 제거한다. 로그인 또는 저장 오류 시 선택을 유지하고 마지막 연결 단계에서 재시도할 수 있다. 임시 데이터가 손상됐으면 계정에 적용하지 않는다. 연결을 건너뛰면 연결 표시를 해제하며 기존 계정 데이터는 바꾸지 않는다.

기존 Kakao provider, PKCE 콜백 URL, 공개 Supabase 키를 재사용한다. 추가 환경변수·권한·DB 마이그레이션은 없다. 카카오톡 메시지 권한을 요청하거나 메시지를 발송하지 않는다.

검증: `npm test`, `npm run build`. 단위 시험은 작품·캐릭터 복수 선택, 작품 전체 선택, 임시 데이터 검증, 기존 관심사 보존과 별칭 중복 방지를 포함한다. 브라우저에서는 단계 이동·검색·선택 취소·캐릭터 연결·홈 건너뛰기·모바일 및 테마를 확인한다.
