# 홈 폼 탭 (2026-11-01)

검색창 아래에 최고 인기 폼 / 맞춤 추천 폼 / 알림 설정한 폼을 배치한다. 한 번에 하나의 tabpanel만 보이며, 좌우 방향키·Home·End로도 이동할 수 있다. 기존 팔레트, 테마 저장, 검색/상세/등록/구독/웹 알림은 유지한다.

2026-11-02: 각 탭과 검색 결과의 격자/목록 스위치를 작은 공통 규격으로 통일하고 목록 오른쪽 위에 배치했다. 보기 선택은 기존 브라우저 저장 값을 공유한다. 맞춤 탭의 별도 탐색 링크를 제거했다. 알림 설정 안내와 받은 새 알림은 하나의 영역에 통합하며, 실제 새 알림 항목도 격자/목록으로 표시할 수 있다. 개별 알림 설정이 준비 중이라는 안내는 유지한다.

## 실제 연결한 데이터

- 최고 인기 폼: `popular_goods_feed` RPC로 전체 공개·비테스트 게시물 중 실제 상세 조회 기록이 있는 폼만 집계한다. 조회 수 내림차순, 동점은 등록 시각·ID 순, 최대 30개다. 기존 브라우저별·게시물별·하루별 조회 중복 방지를 재사용한다. 조회 0건인 폼은 임의 순위에 포함하지 않는다. 개인/방문자 식별자는 반환하지 않는다.
- 맞춤 추천 폼: 현재 계정의 저장된 작품·캐릭터와 일치하는 공개·비테스트 게시물만 기존 구독 RPC로 조회한다. 결과는 최신 등록순이며, 일치하는 데이터가 없으면 빈 화면을 표시한다. 인기 폼이나 예시 데이터로 채우지 않는다. 작품·판매 상태 필터와 페이지 이동을 유지한다.
- 알림 설정한 폼: 현재 DB에는 항목별 알림 선택이 없고, 구독 전체에 대한 웹 알림 수신 설정만 있다. 따라서 맞춤 결과를 복사해 알림 설정 결과처럼 표시하지 않는다. 아직 연결되지 않았음을 명시하고, 기존 전체 웹 알림 설정 및 받은 알림 목록으로 이동할 수 있게 한다.

## 추가 구현이 필요한 사항

1. 원본 판매 링크 클릭 이벤트 집계와 조회·클릭 통합 인기 점수 정책. 현재 순위는 실제 상세 조회 수만 반영한다.
2. 사용자별 장르 관심 등록·저장 및 장르 매칭. 현재 개인 관심사는 작품·캐릭터만 저장된다.
3. 관심사와 별개인 작품·캐릭터·장르별 알림 선택 데이터/설정 화면, 이를 이용하는 피드 및 신규 알림 매칭. 기존 구독 전체 웹 알림 동작은 변경하지 않는다.

테스트 데이터나 가상 조회 수를 홈에 넣지 않았다. 실제 데이터가 쌓이면 현재 연결한 인기/작품·캐릭터 맞춤 결과가 자동으로 나타난다. 별도 환경변수는 필요 없다.

```sh
python3 scripts/db-admin.py apply supabase/migrations/20261101010000_popular_home_feed.sql
python3 scripts/db-admin.py sql supabase/tests/popular_home_feed.sql
npm test
npm run build
```

DB 시험은 조회 순서·중복 조회·0건/비공개/테스트 제외·방문자 정보 비공개를 확인하고 모든 fixture를 롤백한다.
