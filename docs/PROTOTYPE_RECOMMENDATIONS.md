# 인기·맞춤 추천 프로토타입

기존 탭/카드/검색/관심사/판매 상태 필터/폼 알림과 테마를 재사용한다. DB·프로필·실제 굿즈·로그인은 바꾸지 않는다.

## 인기 폼

체험 모드에서는 assets/prototype-feed.js가 원래 예시 80개/40개 폼에서 서로 다른 폼 10개를 고른다. 대표 상품의 작품 기준 괴담출근 4개, 어바등·원신·스타레일·헌헌·나루토·니지산지 각 1개다. 같은 폼에 다른 작품도 있어 전체 상품 태그에는 작품이 함께 표시될 수 있다. 편집한 체험 구성이지 실제 트래픽 순위가 아니며 조회 수를 생성하지 않는다. 검색에는 전체 80개를 유지한다.

실제 모드의 기존 popular_goods_feed는 실제 조회 기록을 쓰고 page_size만 10으로 줄였다.

## 맞춤 추천

체험 모드는 좋아하는 인물에서 새 인물로 이어지는 추천을 보여 준다. 작품 전체 관심사는 그 작품의 체험 카탈로그 인물들을 기준으로 확장한다. 이미 등록한 인물/작품 전체에 포함된 인물은 다시 추천하지 않는다.

- 외형 예시: 카카시·쿠즈하·파이논의 밝은 머리색, 나루토·어벤츄린·크라피카의 금발이라는 소규모 편집 태그를 사용한다. 얼굴·이미지 자동 분석이나 객관적 유사도는 아니다. 모든 작품의 외형 데이터가 있는 것은 아니다.
- 취향 예시: 22명에 대한 가상 선호 조합을 명시적으로 하드코딩했다. 실제 다른 회원의 관심사/행동/구매를 수집하거나 분석하지 않으며 통계·퍼센트·실제 이용자 수를 표시하지 않는다.
- 후보는 최대 6명, 연결 폼은 최대 12개. 후보에 작품명·캐릭터명·외형/취향 예시 구분·기준을 표시한다. 굿즈 보기 버튼은 기존 통합 검색으로 연결한다.
- 추천 기준 작품 필터와 판매 상태 필터를 사용한다. 관심사 없음/지원 예시 없음은 빈 안내를 표시한다. 임의의 전체 인기 목록으로 대체하지 않는다.
- 실제 모드는 기존 계정 관심사와 정확히 일치하는 피드를 유지한다. 실제 이용자 기반 추천 엔진과 전체 외형 분석은 아직 연결하지 않았다.

앱 상단, 첫 안내, 체험 배너, 탭별 설명, 상세 안내에 프로토타입 체험용임을 표시한다. 예시 콘텐츠 배지와 구매 링크 없음은 유지한다.

캐릭터 표기 참고: [나루토 공식 방송사 소개](https://www.tv-tokyo.co.jp/contents/naruto/chara.html), [쿠즈하 공식 프로필](https://www.nijisanji.jp/talents/l/kuzuha), [파이논 공식 업데이트 안내](https://hsr.hoyoverse.com/en-us/news/157441). 외형 태그는 이 프로토타입을 위한 편집 판단이며 소속/정체성/성격을 자동 추론하지 않는다. 이미지 자산은 가져오지 않았다.

검증: npm test 36개, 빌드. 인기 폼 10개·중복 없음·대표 괴담출근 4개, 22명 전체의 가상 취향 경로와 연결 상품 정확성, 등록 관심사 중복 추천 방지, 판매 상태 필터 및 미지원 관심사 빈 결과 시험. 브라우저에서 카카시 선택→추천 후보/폼→파이논 검색 5개 연결 확인. 모바일 320px 양 테마 가로 넘침 없음.
