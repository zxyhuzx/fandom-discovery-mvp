# 별줍 안내 문구 기준

별줍은 ‘별을 줍다’에서 나온 이름이다. 흩어진 작품·캐릭터·창작자·굿즈 정보를 발견하고 연결하는 경험을 뜻한다. 굿즈를 직접 판매하는 서비스가 아니다.

자연스러운 존댓말을 사용하며, 기능 설명을 감성보다 우선한다. 별과 발견 이미지는 첫 이용 안내나 완료 메시지에 가볍게 사용한다. 버튼은 관심사 등록, 관심사 저장하기, 상세 보기, 원본 판매 페이지로 이동처럼 행동을 명확히 쓴다.

| 상황 | 문구 |
| --- | --- |
| 첫 이용 | 좋아하는 세계를 알려주세요 |
| 관심사 안내 | 관심 있는 작품과 캐릭터를 등록하면, 별줍에 등록된 관련 굿즈를 모아 보여 드려요. |
| 첫 관심사 저장 완료 | 이제 나만의 별을 찾아볼까요? 등록하신 관심사와 관련된 굿즈를 둘러보세요. |
| 서비스 홈 | 오늘 발견한 굿즈 / 좋아하는 작품과 캐릭터의 새로운 소식을 살펴보세요. |
| 관심사 매칭 없음 | 아직 발견된 굿즈가 없어요 / 다른 작품을 탐색하거나 관심사를 추가해 보세요. |
| 검색 결과 없음 | 찾으시는 굿즈가 보이지 않아요 / 검색어를 바꾸거나 다른 작품과 캐릭터를 찾아보세요. |
| 알림 없음 | 아직 새로운 소식이 없어요 / 관심사와 관련된 굿즈 소식이 생기면 이곳에서 확인할 수 있어요. |

자동 수집은 구현하지 않았으므로 자동으로 찾아낸다고 안내하지 않는다. 개인화 목록은 저장한 관심사와 관리자가 등록한 게시물을 매칭한다. 카카오톡은 준비 중이며 실제 발송 없음 안내를 유지한다. 예시 데이터와 실제 데이터를 구분한다. 기존 색상·라이트/다크 모드·레이아웃은 유지한다.
