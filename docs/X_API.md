# X API 연결 및 비용 검증

2026-11-10 공식 요금 확인. 실제 계정의 콘솔 요금과 청구가 최종 기준입니다.

## 준비된 연결

- 기존 굿즈 업로드 화면의 운영자 전용 도구에 `X 연결 테스트`를 추가했습니다. 일반 회원의 본인 굿즈 업로드는 그대로 유지합니다.
- `x-search` Supabase Edge Function이 사용자 세션과 `is_app_admin()`을 확인합니다. 브라우저에 X 토큰이나 service role 키를 전달하지 않습니다.
- 작품/캐릭터 이름을 따옴표로 묶고 통판·수요조사·선입금 키워드와 결합하여 최근 7일 게시물을 조회합니다.
- 요청당 최대 10개, 페이지 추가 조회·자동 재시도·주기적 수집은 없습니다. 사용자 프로필, 팔로워, DM은 조회하지 않습니다.
- 결과는 원문 확인용입니다. 기존 `goods_posts`에 저장하지 않고, 작가 본인의 업로드로 둔갑시키거나 구독 알림을 생성하지 않습니다. 판매 상태와 작품·캐릭터는 자동 확정하지 않습니다.
- 이미지 복제, X 계정으로 로그인, X에 글쓰기, 카카오 발송은 이번 연결에 포함하지 않습니다.

## 비밀 설정

Supabase 함수 비밀 설정에만 등록합니다. 실제 값은 저장소, 문서, 채팅 또는 브라우저 코드에 넣지 않습니다.

| 이름 | 의미 |
| --- | --- |
| X_BEARER_TOKEN | X 앱의 서버용 Bearer Token |
| X_API_ENABLED | 명시적으로 true일 때만 유료 조회 허용 |
| X_MONTHLY_RESOURCE_LIMIT | 월 예약 건수. 10~4000만 허용. 승인 예산에 맞게 설정 |
| X_DAILY_RESOURCE_LIMIT | 하루 예약 건수. 기본 20, 최대 100 |

토큰 또는 활성화/월 한도 설정이 없으면 유료 호출 없이 중지합니다. X 콘솔에서도 별도 달러 지출 한도를 설정하고 자동 충전을 끕니다. 월 한도는 UTC 달력 기준이고 X 청구 주기와 다를 수 있으므로 콘솔 한도를 병행해야 합니다.

`private.x_api_budget`은 호출 전에 10건을 원자적으로 예약합니다. 응답이 0건이거나 실패해도 자동 환급하지 않아 실제 사용보다 보수적으로 중단합니다. 이 수치는 청구서가 아닙니다. X 가격 변경, 중복 과금 예외, 다른 경로의 사용은 콘솔에서 확인합니다. 일반 사용자에게 테이블과 예산 RPC 권한이 없습니다.

## 배포와 검증

1. `20261110170000_x_api_budget.sql` 마이그레이션 적용
2. `supabase/tests/x_api_budget.sql` 롤백 테스트
3. `npx supabase functions deploy x-search --project-ref plxdnppizgvrqakjyehm --no-verify-jwt --use-api`
4. 운영자가 실제 콘솔 약관·결제 화면에서 직접 동의/결제한 뒤 서버 비밀 설정 등록
5. 일반 사용자/비로그인 요청은 401 또는 403인지 확인하고, 운영자 검색 1회로 연결 검증
6. X 콘솔에서 실제 반환량·사용액·한도 확인. 웹은 기존 GitHub main push 자동 배포 사용

## 수익과 비용 가정

X Posts:Read $0.005/반환 게시물. 검색 요청 횟수나 최종 채택한 판매 폼 수 기준이 아닙니다. 관련 없는 결과를 버려도 반환된 게시물에는 비용이 발생할 수 있습니다. 사용자 프로필은 별도 $0.010/반환 사용자입니다. UTC 같은 날 중복 조회는 대체로 중복 과금이 제거되지만 공식 문서는 예외 가능성을 명시합니다.

아래는 **환율 1달러=1,500원, 월 구독료 2,000원, 서버 예산 Vercel Pro $20 + Supabase Pro $25, 1인 운영**을 가정한 비교입니다. 현재 실제 청구액이나 유료 전환율을 측정한 결과가 아닙니다.

| 월 게시물 반환량 | X 읽기 비용 | 서버 기본료 포함 | 비용만 충당할 유료 구독자 |
| --- | ---: | ---: | ---: |
| 3,000 | $15 / 22,500원 | 90,000원 | 45명 |
| 30,000 | $150 / 225,000원 | 292,500원 | 147명 |
| 300,000 | $1,500 / 2,250,000원 | 2,317,500원 | 1,159명 |

세금·결제 수수료·트래픽 초과·도메인·카카오 메시지·AI·인건비·고객 확보비를 제외한 비용 충당선이며 이익 발생선이 아닙니다. 이용자 1,000명 중 5%가 월 2,000원을 결제한다고 **가정**하면 매출은 10만원입니다. 월 3,000건 수집 예산은 기본 서버비와 함께 대략 충당하지만 30,000건은 부족합니다. 설문 123명은 실제 유료 고객 수가 아닙니다.

별줍 자체 설문, 클릭/알림 버튼 이벤트 기록은 X API 요금 대상이 아닙니다(자체 DB/분석 비용은 별도). X Activity 웹훅의 post.create는 $0.005/이벤트 등 별도 요금이므로 이번에는 연결하지 않습니다. 같은 수집 결과를 여러 고객에게 매칭하는 자체 DB 처리는 X 재조회 없이 공유해야 합니다.

처음에는 소액 예산으로 읽은 게시물 중 실제 진행 중인 관련 폼의 비율, 신규 폼 중복률, 마감 시각 확인 가능률을 측정합니다. 채택률 10%면 유효 폼 1개당 읽기 비용 $0.05, 1%면 $0.50입니다. 계정 조사나 전체 팔로워 수집 없이 공개 판매 공지에 한정합니다.

## 실제 홈 카드 연결 (2026-11-10)

- 이미 API로 확인한 공개 공지 10개 중 같은 회지의 이전 수요조사 공지 1개를 중복으로 제외하고 9개를 공개했습니다. 추가 X 호출은 하지 않았습니다.
- 기존 goods_posts 구조를 재사용하되 source_kind=x_discovery, created_by=null, source_checked_at으로 작가 본인 등록과 구분합니다. 일반 회원은 이 출처를 지정하거나 다른 사람의 등록물로 가져올 수 없습니다.
- 전체 글과 이미지를 복제하지 않고 짧은 편집 제목·요약, 확인된 마감일, X 원문 링크를 저장했습니다. 작성자명·캐릭터가 불확실한 경우 추측하지 않습니다. source_url은 판매 폼을 안내한 X 원문이며, 개별 폼의 최종 판매 상태를 보증하지 않습니다.
- source_kind=x_discovery 가져오기는 신규 알림 생성 트리거에서 제외합니다. 실제 계정의 폼 알림 저장·상세 화면·검색·구독 매칭은 기존 경로를 재사용합니다.
- 기본 홈과 탐색을 실제 DB 모드로 전환했습니다. 예시 80개는 삭제하지 않고 별도 예시 모듈에 유지합니다. 기존 튜토리얼의 비로그인 관심사는 계속 로컬에 저장하며 실제 데이터와 정확히 일치하는 목록을 필터링합니다.
- home_goods_feed는 공개·비테스트·미삭제 게시물만 반환합니다. 실제 상세 조회가 있으면 먼저, 조회가 없는 폼은 최근 등록순으로 보여 줍니다. 가짜 인기 기록은 만들지 않았습니다. 기존 popular_goods_feed의 양수 조회 전용 계약은 유지합니다.
- 이번 목록은 수동 검토한 스냅샷입니다. 홈 방문이나 새로고침이 유료 API 호출을 실행하지 않습니다. 추가 검색 결과를 자동 공개하는 기능, 주기적 갱신, 이미지 권한 확보는 이번에 구현하지 않았습니다.

- 실제 게시물 도입 후 발생한 관심사 조회 시간 초과를 개선했습니다. 구독 조회는 저장된 work_key와 작품별 catalog_characters 별칭을 사용하고, 기존 다국어·계정 격리·페이지 이동 계약은 유지합니다. 공개 홈은 별도 읽기 전용 클라이언트로 로그인 복구와 독립적으로 로드합니다.
