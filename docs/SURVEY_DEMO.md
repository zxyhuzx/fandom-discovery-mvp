# 설문조사 체험 콘텐츠

기존 `goods_posts` 화면 필드와 검색·관심사·카드·상세·테마를 재사용한다. DB에 예시 굿즈를 넣지 않는다. 실제 게시물·계정 관심사·알림 기록은 삭제하거나 덮어쓰지 않는다.

## 데이터

- `assets/survey-data.js`: 결정적으로 생성하는 정확히 80개. 22명 × 단독 3개 = 66개, 작품별 조합 1개 + 공통 1개 = 14개.
- 7개 작품별 개수: 괴담출근 14, 어바등 11, 원신 11, 붕괴: 스타레일 11, 헌터×헌터 11, 나루토 8, 니지산지 14.
- 가상 작가 10명, 굿즈 종류 8개. 공통 굿즈는 해당 작품의 명시된 인물을 모두 연결하여 각 캐릭터 검색에도 표시한다.
- 기존 필드(title, work_name, character_names, seller_name, sale_status, sale_info, sale_start/end, created_at, thumbnail_url, is_test 등)를 사용한다. 파일 예시에만 `product_types`, `sale_type`, `search_keywords`, `is_survey_example`을 추가한다. 실제 DB 열 추가는 없다.
- 모든 예시 `source_url`은 null. 구매 링크 없음, 조회 수/인기 수치 없음, 알림/발송 생성 없음. 실제 판매 정보와 섞지 않는다. 홈의 기존 인기 탭 구조를 유지하되 체험 모드에서는 ‘실제 인기 순위가 아님’과 예시 게시일순임을 명시한다.
- `assets/survey/*.svg`: 직접 만든 기하학적 굿즈 형태 8종. 외부 이미지·캐릭터 초상·공식 로고·작가 그림을 사용하지 않는다.
- `assets/survey-names.js`: 사용자 제공 이름을 기존 작품별 명칭/별칭에 병합. 히소카→히소카 모로, 곤→곤 프릭스, 카카시→하타케 카카시, 로렌 이로하스→기존 로렌 이로아스 항목 재사용. 새로운 작품이나 중복 인물 키를 만들지 않는다.

## 체험과 계정 경계

`config.surveyDemoEnabled: true`가 체험 기본값이다. 실제/체험 모드 전환은 기존 예시 버튼을 재사용하며 브라우저 선택을 유지한다. 체험 모드의 비로그인 사용자는 기존 관심사 UI에서 등록된 이름을 골라 `WELCOME_DRAFT_KEY`에 저장하고 동일한 관심사 매칭 함수로 피드를 확인한다. 첫 방문 선택도 같은 임시 데이터를 사용한다. 실제 모드의 계정 저장·프로필·알림·업로드 접근 권한은 그대로 유지된다.

로그인한 사용자의 맞춤 피드는 계정 구독을 사용한다. 계정 구독을 수정·저장하면 기존 DB 저장 로직을 사용한다. 비로그인 임시 관심사를 자동으로 계정에 덮어쓰지 않는다. 예시 굿즈 상세 조회는 실제 조회 통계에 기록하지 않는다.

## 설문 링크와 종료

`assets/config.js`의 `surveyUrl`에 HTTPS 설문 주소를 입력하고 빌드·배포하면 ‘별줍 체험 설문에 참여해 주세요’ 버튼이 표시된다. 빈 값이나 HTTPS가 아닌 주소는 버튼을 숨긴다. 현재는 빈 값이다. 빌드는 기존 공개 Supabase 설정과 함께 이 설정을 전달한다. 비밀 정보는 넣지 않는다.

체험 종료 시 `surveyDemoEnabled`를 false로 바꾸면 기존 브라우저 선택과 무관하게 실제 모드로 시작하고 체험 버튼·배너·예시 상세를 숨긴다. 완전히 제거하려면 `survey-data.js` 연결·전환 버튼과 배너·이미지 파일을 제거한다. DB 굿즈 삭제 작업은 필요 없다. 이름 별칭 마이그레이션은 기존 구독 호환을 위해 유지한다.

## 검증

- `npm test`: 기존 21개와 체험 데이터 4개, 총 25개. 정확한 개수, 전원 단독 3개, 작품/인물/작가/굿즈 검색, 조합별 모든 인물 노출, 판매 유형·상태, 관심사 정확 매칭, 별칭 중복 방지, 이미지 외부 자원 없음, 설문 링크 검증.
- `npm run build`
- `python3 scripts/db-admin.py sql supabase/tests/survey_aliases.sql`: 계정과 같은 별칭 정규화. DB 입력 없이 롤백.
- 브라우저: 실제 로그인 세션 보존, 비로그인 별도 로컬 출처에서 80개 표시→신해량 관심사 저장→맞춤 5개→새로고침 유지. 헌헌 검색 11개, 밤결 공방 검색 8개, 조합 상세·이미지·구매 링크 없음 확인. 실제 모드로 바꾸면 관심사 관리 로그인 안내 확인. 320px 격자·목록·상세 및 라이트/다크 가로 넘침 없음.
- 실제 카카오 로그인 승인 완료는 외부 계정 설정 때문에 이번 작업에서 새로 시험하지 않았다. 기존 인증 코드를 재사용하고 기존 로그인 세션이 유지됨을 확인했다.
