# 별줍 서비스 화면

기존 랜딩(`/`)과 HTML/CSS/JavaScript + Supabase + Vercel 구성을 유지한다. 서비스는 `/app.html`이며 해시 라우팅을 쓴다.

| 경로 | 동작 |
| --- | --- |
| `#home` | 비로그인 전체 소식 / 로그인 관심사 기반 최근 소식 |
| `#explore` | 비로그인 허용. 검색, 작품·캐릭터·판매 상태 필터, 최신순 |
| `#goods/게시물UUID` | 공개 상세 조회와 원본 판매처 링크. 최근 100개 밖 게시물도 개별 조회 |
| `#login` | 기존 카카오 OAuth + PKCE 사용. 회원가입은 카카오 인증 과정에서 처리 |
| `#onboarding` | 첫 로그인, 관심사 없음, 건너뛰기 기록 없음인 경우 표시 |
| `#interests` | 작품별 캐릭터 선택, 여러 관심사 편집 후 저장 |
| `#notifications` | 자기 알림 조회·읽음 처리·관련 상세 이동 |
| `#profile` | 웹 알림 수신 설정, 관심사 관리, 현재 세션 로그아웃 |
| `#admin` | 기존 관리자 권한 유지. 수동 게시물 입력과 모의 대기열 |

로그인하지 않고 저장·알림에 접근하면 로그인 안내 후 원래 목적지로 연결한다. 첫 로그인 온보딩이 필요한 경우 온보딩을 먼저 제공한다. 기존 관심사가 있거나 저장/건너뛰기를 완료한 계정은 다시 등록 화면을 강제하지 않는다. 관심사를 모두 지운 경우에도 완료 기록을 유지하며 홈에서 등록 안내를 제공한다.

## DB 변경

`supabase/migrations/20261025150000_service_home.sql` 적용 완료.

- 익명은 goods_posts의 공개 게시물과 공개용 컬럼만 읽는다. 비공개 게시물, created_by 사용자 UUID, 관심사·알림·개인 설정은 노출하지 않는다.
- goods_posts에 seller_name, platform_name, is_test 추가. 관리자만 입력한다. 테스트 게시물은 추천과 알림 생성에서 제외한다.
- user_preferences는 자기 계정만 조회·저장한다. onboarding_completed, web_notifications를 보관한다.
- save_my_interests RPC는 auth.uid()만 대상으로 목록 교체와 온보딩 완료를 원자적으로 저장한다. 잘못된 입력이면 기존 목록이 복구된다. 최대 100개.
- 새 게시물 알림 생성 시 웹 알림 설정을 확인한다. 이미 받은 알림은 수신 설정을 꺼도 남는다.
- 외부 발송은 여전히 kakao_mock만 지원한다. 실제 카카오톡 메시지·스크래핑·결제 기능은 없다.

## 데이터와 테마

작품·캐릭터 초기 카탈로그는 assets/domain.js의 WORKS/CHARACTERS에 서로 연결되어 있다. 제공 목록에 없는 작품·캐릭터도 직접 입력할 수 있다. 저장은 기존 work_name/character_name 구조를 재사용한다. 매칭은 작품 별칭 정규화와 캐릭터 이름 일치 기준이다. 캐릭터 별명·줄임말 자동 통합은 아직 제공하지 않는다.

실제 게시물은 관리자 등록 데이터만 사용한다. 예시 버튼으로만 보이는 3개 예시는 프런트 화면 체험용이며 실제 판매 링크나 알림을 만들지 않는다. 판매 플랫폼이 비어 있으면 원문 도메인을 표시하고 창작자·일정이 없으면 미등록으로 안내한다. 탐색은 최근 100개, 알림은 최근 50개 기준이며 대규모 페이지네이션은 추후 확장한다.

기존 다크 모드 색상 토큰은 변경하지 않았다. assets/brand.css에서 data-theme="light"에만 별도 토큰을 추가했고, 기존 남색·밝은 텍스트 팔레트를 재사용한다. assets/theme.js가 선택 모드를 브라우저 localStorage에 유지하며 랜딩과 서비스에서 공유한다. 계정 간 동기화는 하지 않는다.

## 검증

```sh
npm run build
npm test
npm run test:db
python3 scripts/db-admin.py sql supabase/tests/service_home.sql
```

DB 시험은 트랜잭션 ROLLBACK으로 fixture를 제거한다. 익명 공개 조회/비공개 차단, 계정별 설정 격리, 목록 저장 실패 시 복구, 온보딩 건너뛰기 지속, 알림 설정에 따른 생성, 기존 중복 방지와 모의 발송을 확인한다.

브라우저에서는 비로그인 검색·예시 상세·로그인 안내, 카카오 기존 계정 로그인, 작품별 캐릭터 표시와 다중 선택/삭제, 관심사 저장과 홈 이동, 알림 설정 저장, 테마 새로고침 유지, 모바일 390px 가로 넘침을 확인한다. 새 실제 카카오 계정을 별도 만들지는 않으며 첫 계정 분기와 건너뛰기는 로직·DB 시험으로 보완한다.
