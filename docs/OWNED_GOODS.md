# 작가 본인의 굿즈 등록과 마이페이지 연결

기존 #admin 굿즈 업로드 폼을 재사용한다. 새 업로드 페이지나 제작자 메뉴/공개 홈은 만들지 않았다. 로그인한 사용자가 작가로서 자기 굿즈를 등록할 수 있다. 관리자 모의 발송 도구와 테스트 게시물 선택은 기존 관리자에게만 표시한다.

## 등록자 및 서버 권한

- 기존 goods_posts.created_by를 등록자 ID로 사용한다. 새 등록은 현재 로그인 사용자 ID를 명시하고, 서버 기본값도 auth.uid()다.
- 기존 등록자 값은 이전하지 않는다. 다른 사용자 ID로 신규 등록하거나 기존 게시물의 created_by를 바꾸는 것은 RLS/열 권한/트리거로 차단한다.
- 공개 게시물은 기존처럼 열람 가능하다. 비공개 게시물은 작성자만 읽을 수 있다. 수정은 작성자이며 삭제되지 않은 행에만 허용한다.
- delete_my_goods RPC는 auth.uid()로 작성자를 확인하고 공개를 취소한 뒤 deleted_at을 설정한다. 삭제된 행은 목록·검색·상세에서 숨기며 일반 클라이언트가 등록자를 변경하거나 삭제를 복원할 수 없다. 서버에서의 복구 여지는 남긴 논리 삭제다. 기존 URL 유일성은 유지하므로 삭제했던 URL을 그대로 신규 등록하면 중복 안내가 나온다.
- 등록자 위조/기존 행 도용을 차단하는 기능이다. 외부 판매 폼의 실제 소유자를 인증하거나 작가 인증을 수행하는 기능은 아니다.

## 기존 화면 재사용

마이페이지에 내가 등록한 굿즈를 추가했다. DB에서 created_by=현재 사용자, deleted_at IS NULL 조건으로 조회한다. 로컬 예시 80개는 조회에 섞지 않으며 마이페이지 목록은 DB 테스트 게시물도 제외한다. 기존 업로드 화면의 관리 목록에서는 본인이 등록한 DB 테스트 게시물을 계속 관리할 수 있다.

제목·대표 이미지·작품·캐릭터·판매 상태·공개 여부, 기존 상세 링크, 수정·삭제 버튼을 표시한다. 수정은 같은 업로드 폼에 현재 값(일정 포함)을 채워 저장한다. 등록/수정 후 마이페이지로 돌아오고, 수정·삭제 시 오래된 피드 캐시도 제거한다. 프로필 user_profiles.user_id와 goods_posts.created_by는 같은 auth.users ID로 연결되어 이후 공개 홈에 재사용할 수 있다. 현재는 공개 프로필이나 제작자 홈을 추가하지 않았다.

마이페이지에서 중복되던 사진·닉네임·배너는 제거했다. 기존 프로필 화면과 편집, 구독 관리, 알림, 기존 업로드 경로는 유지한다. 새 환경변수는 없다.

## 최초 방문

first-visit.js의 방문 키와 Supabase 로그인 세션을 기준으로 판단한다. 신규 비로그인 방문은 안내를 먼저 보여 주며 안내를 처음 표시할 때 방문을 기억한다. 재방문/로그인 계정은 홈으로 이동한다. 기존 임시 관심사와 둘러보기 기록도 방문 기록으로 인정한다.

다른 기기에서 로그아웃한 기존 계정은 로그인하기 전까지 기존 계정인지 알 수 없다. 브라우저 기록을 지우면 비로그인 첫 방문으로 처리한다. 저장 공간을 쓸 수 없는 환경에서도 안내에서 홈으로 나가는 링크의 entry=welcome 표식으로 반복 이동을 막는다.

/?tutorial=1은 사용자가 명시적으로 안내를 다시 보는 링크다. Q&A에도 동일 링크가 있다. 계정 정보를 지우거나 로그아웃시키지 않고 처음 화면을 다시 볼 수 있다.

## 확인

- npm test: 33개. npm run build.
- supabase/tests/owned_goods.sql: 일반 계정 등록/프로필 관계/수정/삭제, 소유자 위조 및 재할당·타 계정 수정/삭제 차단, 비공개·삭제 행 노출 차단. 모든 시험 기록 롤백.
- npm run test:db: 기존 구독·알림·중복 방지·모의 대기열 통과. 이전의 관리자 전용 신규 등록 가정은 새 요구에 맞춰 ‘등록자 위조 차단’ 시험으로 변경했다.
- 별도 임시 일반 계정으로 기존 폼 등록→마이페이지 제목·이미지·상태 표시→수정→새로고침→자기 비공개 상세→삭제→빈 목록을 브라우저에서 확인했다. 시험 등록은 비공개였으며 사용자 알림을 생성하지 않았다.
- 모바일 320px 가로 넘침 없음과 테마 전환 확인. 새 로컬 출처에서 직접 app 진입 시 안내 우선, 재방문 홈, 로그인 계정 홈, 명시적 안내 다시 보기 확인.
